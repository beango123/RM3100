# RM3100 单传感器采集说明

当前固件和电脑端程序只使用**传感器 2 通道**（CS2 / DRDY2），用于单独排查和采集当前正常工作的那只模块。传感器 1 不会被初始化、触发或读取。

## 接线

| 信号 | STM32F103C8T6 引脚 |
|---|---|
| SPI1 SCK / MISO / MOSI | PA5 / PA6 / PA7 |
| 正在使用的 CS2 / DRDY2 | PA1 / PA3 |
| USART1 TX / RX | PA9 / PA10 |

RM3100 模块、STM32 和 USB 转串口模块需要共地。USB 转串口模块的 RX 接 STM32 PA9（TX），TX 接 PA10（RX），使用 3.3 V 逻辑电平。上电前核对模块引脚丝印和供电要求。

SPI 使用模式 0、MSB 优先、8 位数据、500 kHz。固件将 X/Y/Z 轴的 Cycle Count 设为 200；每次循环仅向 CS2 对应模块发起一次三轴单次测量，等待 DRDY2 就绪后读取原始数据。固件不控制旋转机构，也不读取旋转角度。

## 串口帧

USART1 默认 115200 波特率。串口仍保留原来的帧结构，以兼容已有解析程序：

```text
RM,seq,trigger1_us,trigger2_us,ready_mask,x1,y1,z1,x2,y2,z2*XX
```

当前帧中 `trigger1_us` 和 `x1,y1,z1` 是未使用的占位字段，值为 0；`trigger2_us` 是 STM32 启动后的微秒计数器值；`x2,y2,z2` 是传感器 2 的有符号 24 位原始计数。`ready_mask` 当前为 `2`（bit 1 置位，表示传感器 2 有效）。`XX` 是 `*` 前 ASCII 字节的异或校验值。帧首的 `RM3100,1,raw24,us` 是协议提示，不是传感器数量。

## 电脑端采集

在 PyCharm 使用的 Python 环境安装串口库：

```powershell
py -m pip install pyserial
```

运行 `rm3100_capture.py`，在文件顶部修改 `SERIAL_PORT` 为电脑识别到的端口号，例如 `COM5`。`BAUD_RATE` 默认 115200；`OUTPUT_CSV` 留空时会自动生成带时间戳的文件名，也可填写文件名。运行后在窗口中点击“开始采集”；窗口内也可选串口和 CSV 路径。

GUI 只显示传感器 2 的 X、Y、Z 轴磁场分量和三轴合成模长。显示读数为原始计数除以 `GAIN_LSB_PER_UT`（当前 75 LSB/µT）后的 µT 值。界面抽帧和刷新间隔只影响显示，不影响采集；CSV 按收到的每帧保存。

CSV 表头仍保持原双传感器格式，便于兼容旧脚本。传感器 1 的 raw 占位值为 0、µT 列为空；传感器 2 列保存有效读数。程序检查帧校验、统计序号跳变，并报告连续重复向量；静止且环境稳定时数值重复不一定表示故障。已有 CSV 文件不会覆盖。

若修改固件中的 Cycle Count，需要同步确认 `GAIN_LSB_PER_UT` 的换算值。75 LSB/µT 是 Cycle Count 200 时的典型增益，精确绝对磁场测量需要对组装后的传感器校准。
