# RM3100 双传感器采集说明

## 一、接线

当前 CubeMX 工程使用以下引脚：

| 信号 | STM32F103C8T6 引脚 |
|---|---|
| SPI1 SCK / MISO / MOSI | PA5 / PA6 / PA7 |
| 传感器 1 CS / DRDY | PA0 / PA2 |
| 传感器 2 CS / DRDY | PA1 / PA3 |
| USART1 TX / RX | PA9 / PA10 |

两块模块、STM32 和 USB 转串口模块需要共地。RM3100 的 SPI、CS、DRDY
分别接到表中对应引脚。上电前请核对模块丝印和供电要求。USB 转串口模块的
RX 接 STM32 PA9（TX），TX 接 PA10（RX）；使用 3.3 V 逻辑电平。

SPI 使用模式 0、MSB 优先、8 位数据、500 kHz，CS 低电平有效且空闲时为高。
固件将每轴周期计数设为 200，然后依次触发两块传感器进行一次三轴测量，等待
各自 DRDY 就绪后读取数据。

## 二、串口数据帧

STM32 通过 USART1，以 115200 波特率发送数据。每行格式如下：

```text
RM,序号,传感器1触发时间us,传感器2触发时间us,就绪标志,传感器1的x,y,z,传感器2的x,y,z*校验值
```

实际串口帧中的字段名示例：

```text
RM,seq,trigger1_us,trigger2_us,ready_mask,x1,y1,z1,x2,y2,z2*XX
```

`XX` 是 `*` 前所有 ASCII 字节的异或校验值。磁场读数以有符号 24 位原始计数
发送。`ready_mask` 的 bit 0 表示传感器 1 读数有效，bit 1 表示传感器 2 读数
有效。两路触发时间是 STM32 启动后的微秒计数器值；计数器为 32 位，约每 71 分钟
回绕一次。每行的两个触发时间可用于计算该组数据的触发间隔。

## 三、电脑接收并保存 CSV

首次使用时在 PyCharm 的 Terminal 中安装 Python 串口库：

```powershell
py -m pip install pyserial
```

在 PyCharm 中打开 `rm3100_capture.py`，修改文件开头的 `SERIAL_PORT`，填入电脑上
USB 转串口模块对应的端口，例如 `COM5`。需要时可以修改 `OUTPUT_CSV` 指定 CSV
文件名；留空则自动按日期时间命名。`BAUD_RATE` 默认是 115200。修改后点击
PyCharm 的运行按钮会打开中文实时监测窗口，在窗口里确认串口后点击“开始采集”。
窗口也可以直接修改串口、波特率和 CSV 路径。相对路径按脚本所在目录解释。
已有的 CSV 文件不会覆盖；再次采集时可清空 CSV 路径，以生成新的文件名。
也可以在终端运行：

```powershell
py tools\rm3100_capture.py
```

点击“停止”或关闭窗口停止接收，程序会保存剩余数据并关闭串口。
脚本会忽略启动提示等非数据行，只保存字段数正确且校验通过
的数据帧。CSV 同时保留原始计数和换算后的微特斯分量，列名为
`sensor1_dx_uT` 至 `sensor2_dz_uT`。

运行时还会提示 STM32 启动时的 RCC 复位标志、序号回退/跳号，以及连续两帧六轴
原始值完全相同的情况。这些提示用于排查复位、串口丢帧和疑似重复测量；连续数值
相同本身不一定是故障，静止且信号稳定时也可能发生。

窗口同时显示传感器1、2，每行分别展示 X、Y、Z 和三轴合成模长 `sqrt(X²+Y²+Z²)`。
两行读数取自同一串口数据帧，直接显示原始计数 (LSB)，不除以灵敏度。复选框统一控制
显示哪些轴；模长始终根据各自传感器全部三轴计算。某只传感器未就绪时，其读数显示 `--`。

默认每10帧抽取一组读数，每500毫秒刷新一次窗口。两个参数都可在采集时修改：
抽取帧数范围1–10000，显示间隔范围50–10000毫秒。屏幕显示最新抽取的帧，
不做平均，也不依次回放积压的历史帧；窗口保留最后读数并显示其接收时间距今多久。
若超过2秒没有收到有效帧，状态栏会提示。

抽帧和刷新设置只影响屏幕显示，CSV仍逐帧保存两只传感器的数据，STM32采集方式
不受影响。`DISPLAY_EVERY_N_FRAMES` 和 `DISPLAY_INTERVAL_MS` 可设置启动默认值。
窗口使用Python自带的Tkinter，额外依赖只有 `pyserial`，请安装到PyCharm正在使用的
解释器环境中。

换算使用 PNI 给出的周期计数 200 时标称增益 75 LSB/µT。若修改了固件中的周期
计数，也要同步修改 `rm3100_capture.py` 中的 `GAIN_LSB_PER_UT`。该增益是典型值；
需要更准确的绝对磁场值时，应对组装后的每块传感器进行校准。

## 四、旋转采集说明

当前固件不控制旋转机构，也不读取旋转角度；它持续采集两块传感器的三轴磁场分量，
并附上采样序号和触发时间。如果只需要磁场分量随时间变化的数据，不需要增加角度
输入。如果之后需要把数据转换成带空间坐标的二维磁场图，再增加角度或位置测量，
并提供传感器间距、旋转轴位置等几何信息。
